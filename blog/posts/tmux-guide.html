tmux is a terminal multiplexer: it lets one terminal window hold many shells, and it keeps those shells running after you close the window or lose your SSH connection. If you have ever had a long training run die because your laptop went to sleep, tmux is the fix. This guide covers the mental model, the everyday commands, a sensible config file, and a few workflows I use on remote servers.

1. Why tmux?

  • Persistence: processes keep running on the server after you disconnect. Reconnect later and pick up exactly where you left off.
  • Splits and tabs anywhere: split a single SSH session into panes and windows, with no GUI needed.
  • One layout per project: keep a session for each project, each with its own editor, logs, and shells, and switch between them in a keystroke.
  • Pairing: two people attached to the same session see the same screen.

2. Installation

# macOS
brew install tmux

# Ubuntu / Debian
sudo apt install tmux

# Fedora / CentOS
sudo dnf install tmux

# Check the version (3.x recommended)
tmux -V

No root access on a shared server? conda install -c conda-forge tmux installs it into your user environment.

3. The Mental Model

tmux has four layers. Once these click, every command makes sense:

Layer What it is Analogy
Server A background process that owns everything. Starts automatically on first use. The browser itself
Session A named group of windows. You attach to and detach from sessions. A browser window
Window A full-screen page inside a session, listed in the status bar. A tab
Pane A rectangular split inside a window, each running its own shell. A split view inside a tab

When you close your terminal or SSH drops, you only lose the client. The server, and every session under it, keeps running.

4. The Prefix Key

Almost every tmux shortcut starts with the prefix, which is Ctrl + b by default. Press and release the prefix, then press the command key. In this guide, prefix d means: press Ctrl + b, release, then press d.

Two shortcuts worth learning first:

  • prefix ?: list every key binding
  • prefix :: open the tmux command prompt (for example, type kill-session)

5. Sessions

5.1 From the shell

# Start a new session named "train"
tmux new -s train

# List sessions
tmux ls

# Attach to a session (or the most recent one if no name is given)
tmux attach -t train
tmux a

# Attach if it exists, otherwise create it
tmux new -A -s train

# Kill a session
tmux kill-session -t train

# Kill everything (the whole server)
tmux kill-server

5.2 Inside tmux

Keys Action
prefix dDetach (the session keeps running)
prefix sPick a session from an interactive tree
prefix $Rename the current session
prefix ( / prefix )Previous / next session

Detach, don't exit. Typing exit closes the shell, and closing the last shell ends the session. Use prefix d when you want to leave something running.

prefix z is the one people forget and then love: zoom into a pane to read a long stack trace, then zoom back out to your layout.

8. Scrolling and Copy Mode

Your mouse wheel does not scroll tmux history by default. Use copy mode instead:

  1. Press prefix [ to enter copy mode.
  2. Scroll with arrow keys, PgUp / PgDn, or (with vi keys enabled) Ctrl + u / Ctrl + d.
  3. Search backward with ? or forward with /, then n / N to move between matches.
  4. With vi keys: press v to start selecting, y to copy.
  5. Press q to leave copy mode. Paste the tmux buffer with prefix ].

The config in the next section turns on mouse support and vi keys, which makes this much friendlier.

9. A Sensible ~/.tmux.conf

tmux reads ~/.tmux.conf on startup. Here is a small config that fixes the most common annoyances:

# ---- Prefix: Ctrl+a is easier to reach than Ctrl+b ----
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# ---- General ----
set -g mouse on                  # click panes, drag borders, wheel-scroll
set -g history-limit 50000       # much longer scrollback
set -g base-index 1              # windows start at 1, matching the keyboard
setw -g pane-base-index 1
set -g renumber-windows on       # no gaps after closing a window
set -sg escape-time 10           # no lag after Esc in vim
set -g default-terminal "tmux-256color"
set -ag terminal-overrides ",xterm-256color:RGB"   # true color

# ---- Easier splits that keep the current directory ----
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"
bind c new-window -c "#{pane_current_path}"

# ---- Vim-style pane navigation and resizing ----
bind h select-pane -L
bind j select-pane -D
bind k select-pane -U
bind l select-pane -R
bind -r H resize-pane -L 5
bind -r J resize-pane -D 5
bind -r K resize-pane -U 5
bind -r L resize-pane -R 5

# ---- vi keys in copy mode ----
setw -g mode-keys vi
bind -T copy-mode-vi v send -X begin-selection
bind -T copy-mode-vi y send -X copy-selection-and-cancel

# ---- Reload this file with prefix r ----
bind r source-file ~/.tmux.conf \; display "Config reloaded"

# ---- A quiet status bar ----
set -g status-position bottom
set -g status-style "bg=default,fg=colour245"
set -g status-left "#[bold]#S  "
set -g status-right "%Y-%m-%d %H:%M"
setw -g window-status-current-style "fg=colour214,bold"

Apply it without restarting tmux:

tmux source-file ~/.tmux.conf

Note: this config reuses prefix l for "move right", which replaces the default "last window" shortcut. Add bind Tab last-window if you want it back. The rest of this post still writes keys as prefix …, so it works with either prefix.

10. Everyday Workflows

10.1 Long-running jobs on a remote server

This is the reason most people install tmux:

# On your laptop
ssh my-server

# On the server
tmux new -A -s exp
python train.py --config configs/base.yaml

# Detach with prefix d, close the laptop, go home.
# Later, from anywhere:
ssh my-server
tmux a -t exp

Combine the two steps with ssh -t my-server tmux new -A -s exp, which attaches if the session exists and creates it otherwise.

10.2 A scripted project layout

tmux commands work from scripts, so you can rebuild a whole workspace with one command:

#!/usr/bin/env bash
SESSION=blog
DIR=~/code/my-site

tmux has-session -t "$SESSION" 2>/dev/null || {
  tmux new-session -d -s "$SESSION" -n editor -c "$DIR"
  tmux send-keys   -t "$SESSION:editor" "nvim ." C-m

  tmux new-window  -t "$SESSION" -n server -c "$DIR"
  tmux send-keys   -t "$SESSION:server" "bundle exec jekyll serve" C-m
  tmux split-window -t "$SESSION:server" -v -c "$DIR"
  tmux send-keys   -t "$SESSION:server.2" "git status" C-m

  tmux select-window -t "$SESSION:editor"
}
tmux attach -t "$SESSION"

10.3 Typing into several panes at once

Need to run the same command on four servers? Open one pane per server, then:

# prefix : then type
setw synchronize-panes on

Everything you type now goes to every pane in the window. Run the same command with off to stop.

10.4 Checking on a job without attaching

# Print the last 20 lines of a pane's output
tmux capture-pane -p -t exp | tail -20

# Send Ctrl+C to a running job
tmux send-keys -t exp C-c

11. Plugins (Optional)

tpm is the standard plugin manager. Install it:

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

Then add to the bottom of ~/.tmux.conf:

set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-sensible'    # widely agreed defaults
set -g @plugin 'tmux-plugins/tmux-resurrect'   # save/restore sessions across reboots
set -g @plugin 'tmux-plugins/tmux-continuum'   # auto-save every 15 minutes
set -g @plugin 'tmux-plugins/tmux-yank'        # copy to the system clipboard

run '~/.tmux/plugins/tpm/tpm'

Reload the config, then press prefix I (capital i) to install. With tmux-resurrect, prefix Ctrl + s saves and prefix Ctrl + r restores your sessions.

Note that tmux sessions survive disconnects, but not reboots. Resurrect restores the layout and working directories; it cannot bring back a process that was killed.

12. Common Gotchas

  • "sessions should be nested with care": you ran tmux inside tmux. Detach first, or press the prefix twice to send it to the inner session.
  • Colors look wrong in vim: set default-terminal and terminal-overrides as in the config above, then restart the tmux server (tmux kill-server).
  • Config changes don't apply: source-file only adds settings. Removed lines stay active until the server restarts.
  • Copy goes to the tmux buffer, not the clipboard: hold Shift (or Option in iTerm2) while selecting with the mouse, or install tmux-yank.
  • Mac Terminal sends Option as a character: enable "Use Option as Meta key" if you bind M- shortcuts.
